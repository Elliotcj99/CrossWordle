# Naughty clues

Hand-written crossword-style clues for the Naughty-mode word list, original to this project and
placed in the public domain (Creative Commons Zero, CC0 1.0).

Each line is `ANSWER<tab>clue`. As everywhere in CrossWordle, a clue never contains the answer
(or its stem). Clues are cheeky but describe the word; they name no real people.
